# ポート／サービス詳細のドラッグ配置と幅調整

🟢 [Done] 2026-10-27

ヘッダーのグリップを動かすと、左・右・下・独立ウインドウの配置ガイドが表示される。ガイドはパネルの小図とアイコンで位置を示し、重なった配置先を強調する。Pointer Captureとリリース位置の判定を使い、実Tauriでもドラッグを確定できる。

- グリップの←／↓／→で左／下／右、Enterで独立表示。Escape、フォーカス喪失、pointercancelは取消。
- 左右の区切り線をドラッグして幅を調整。←→は16px、Shift併用は32px、Home／Endは最小／最大、ダブルクリックは380pxへ戻す。
- 希望幅は280〜600px。現在の作業領域の45%を表示上限とし、幅1100px以下では1列に並べ、区切り線を隠す。
- 日本語・英語・简体中文、フォーカス表示、ARIA separator、reduced motionに対応。説明はツールチップにまとめる。

## 状態と範囲

RustのSharedStateがポート／サービス別の希望幅を所有し、SnapshotのpanelGeometryで全ウインドウへ配信する。ドラッグ中はCSSのプレビューのみ、リリース時に1回だけresize_evidence_panelへ送る。期待する旧幅と一致しない更新は拒否し、最新Snapshotから再操作できる。更新インストール中の変更も拒否する。

希望幅はセッション中のみ保持する。ジョブ開始・停止・ワーカー更新では幅を維持する。選択・文書・観測結果・差分基準・CSVを変更せず、サービスの未保存メモも維持する。

これは固定4配置へのドラッグ操作であり、任意の分割グリッドやタブ結合ではない。OSウインドウを跨ぐポインタードラッグ、高さの共有調整、終了後のレイアウト保存は未実装。独立ウインドウ自体の移動・サイズ変更は既存のOS操作を利用する。
