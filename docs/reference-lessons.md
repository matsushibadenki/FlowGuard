# RabbitWallの調査メモ

RabbitWall（調査時点 `417f204`）はLinuxゲートウェイ向けの別アプリ。以下は設計上の着眼点であり、FlowGuardへコード、画面、地図素材を転用しない。FlowGuardはmacOS上の観測範囲と取得元を前提に、独自に設計・実装する。

- **地理情報**：国別IPデータは地図の図形とは別に扱う。導入は任意とし、データの提供元・ライセンス・取得日・対象バージョン・IPv4／IPv6の対応・期限切れを表示する。対象外や照合不能は不明のままとし、推定国を接続先の本人性や実際の通信経路と混同しない。地図素材とIPデータは別々にライセンスを確認する。
- **ドメインの候補**：DNS応答に基づく名前とOSの逆引き結果は取得元を分け、時刻・TTL・候補であることを表示する。共用IP、キャッシュ、暗号化DNSや収集漏れにより、アプリが使った名前や相手の本人性を確定できない。明示設定と収集上限が必要で、DNSサービス自体の動作に依存しない観測設計を検討する。
- **欠落と鮮度**：収集失敗、遅延、停止、ネットワーク変更を正常な空結果と区別し、観測できなかった接続を終了済みと断定しない。古い結果と取得時刻を明示し、情報が欠けているときはグラフにも不確定として反映する。
- **時間帯別の集計**：転送量のグラフは、取得元が提供する実測カウンターと継続性を検証できる場合に限る。初回は基準値として扱い、再起動・カウンター減少・観測間隔の欠落は差分不確定とする。取得範囲、欠落、保存期間を表示し、接続件数からバイト数を推計しない。
- **制御と観測の分離**：表示用の補助データや名前取得が停止しても、通信制御の適用状況と混同しない。RabbitWallのLinuxゲートウェイ方式をmacOSにそのまま当てはめず、FlowGuardのProvider応答・期限・復旧の仕組みを個別に検証する。

これらは今後の検討項目であり、未実装の機能や検証を完了したことを意味しない。データソースの利用条件は導入時点で改めて確認する。
