# LANシート拡張（2026-10-26）

## 実装範囲

- Rust共有Inventoryに表示名（80文字）、列幅（80〜480px）、初回観測、ベンダー候補、保存履歴を追加。表示名とコメントは収集世代・編集前値を照合し、別アドレスへ移植しない。初回観測は同じネットワーク条件・アドレス・MACのセッション内記録であり、機器の初参加時刻ではない。
- シートは全データ列のソート、IP範囲／応答／差分の絞り込み、別名・コメント・複数取得名の検索に対応。ヘッダー、選択欄とアドレスを固定。80行超は88px固定行＋前後バッファを描画し、最後の行まで到達可能。DOMにない行も検索・選択・全結果CSVの対象。狭幅のアドレス列は表示可能幅へ縮め、表内だけ横スクロールする。
- IPv4 Pingは従来のprivate /24〜/30・最大254件を維持。任意の部分範囲は利用可能なpeerを両端とし、範囲外／ネットワーク／ブロードキャスト／自ホストの指定をRustで拒否。自ホストが範囲の途中にある場合は除外する。同時1〜4件、待機100〜1000ms、バッチ間隔0〜1000ms。実行時の条件を結果・CSV・履歴へ保持。RTTは`ping`応答のtime値だけを採用し、0と未取得を区別する。バッチ間の停止待ちは25ms刻み。
- インターフェース・IP・マスクに加え、取得できたIPv4ゲートウェイとSSIDを収集中の確認に使用。SSIDはOSが開示した場合だけ表示し、権限を要求／回避しない。取得不能や同一値を維持する切替、確認間の一時的な切替、収集完了後の経路変化は全て識別できるとは扱わない。

## 任意の機器情報

名前は従来どおり既定オフ。選択したOSリゾルバーまたはmDNSの応答から最大8名を保持し、値・取得元・時刻・未取得状態を表示。複数名でも機器を統合しない。

広告サービスとSMB取得も既定オフで、開始前に有効化する。

- mDNS: 選択インターフェース内で`_smb._tcp.local`／`_ssh._tcp.local`／`_http._tcp.local`／`_https._tcp.local`のPTR・SRV・A／AAAAを照会。1照会600ms・16RDATA、最大8インスタンス候補、1アドレス最大8広告。DNS-SDの固定API・強制multicastを使用し、`.local`以外へ名前解決を進めない。広告のIPと観測IPの一致は候補照合であり本人性の証明ではない。
- SMB名／ドメイン: 同じprivate IPv4サブネットの最大32peerへ、送信元IP・インターフェースを固定したunicast UDP137 NBSTATを1回送信。同時4・600ms・最大2048byte。transaction、送信元IP／ポート、応答種別、長さと最大32name recordを検証。SMBログイン、資格情報送信、設定変更は行わない。NetBIOSを停止したSMB機器は取得できず、応答なしはSMB不在やドメイン非所属の証明にならない。
- OUI: [IEEE公式MA-L一覧](https://standards.ieee.org/products-programs/regauth/)から2026-10-26に取得した40,394登録をオフライン照合。元CSVのSHA-256は`src-tauri/resources/OUI-SOURCE.md`。表示は/24の登録組織候補であり製造元や機器識別ではない。ローカル管理／ランダム化／multicast MACを除外。MA-M／MA-S／IABの下位割当ては扱わない。実行時に外部照会しない。

## 明示保存と候補

正常完了・エラーなしの収集だけを保存可能。最大8回・合計8MiB、アプリデータ領域の`document-v1.lan-history.json`へ0600の一時ファイル・sync・renameで保存する。失敗で既存ファイルやメモリの保存済み一覧を更新しない。現在の選択やコメント等は再収集で消えるが、明示保存した回は次回起動後も読み取り専用で参照可能。

通常Snapshotは履歴の概要だけを送り、選択した回の内容はRustから個別取得する。過去の結果から現在のTCP確認を開始したり、現在のサービス／診断結果を結び付けたりしない。

同じネットワーク条件の保存結果に同じグローバル管理MAC・異なるIPがあれば、最大4つの旧IPを候補表示する。自動統合、コメント・表示名の引き継ぎは行わない。MACの重複・偽装・再利用は判定できない。

## 公開ネットワーク

LAN一覧と独立し、セッション内の明示許可＋取得操作だけで[IPinfoの公開API](https://support.ipinfo.io/hc/en-us/articles/30792479436562-What-Is-the-Difference-Between-Using-the-Authenticated-Free-Plan-and-the-Public-API-With-No-Account)へGETを1回送る。送信先は`https://ipinfo.io/json`固定、リダイレクトなし、標準のTLS検証、6秒・8KiB・30秒間隔。送信先にはこのMacの公開IPとHTTPS接続情報が見えることを許可欄と情報表示で示す。LANのIP／MAC／名前／シートを送らない。

採用するのは公開IP・org・countryだけで、応答に含まれ得る座標等を状態へ保持しない。組織／ISP・国は提供元の候補であり、VPN／プロキシ出口の可能性もある。選択中LANや機器の所在地と関連付けない。取消で結果を消し、旧操作の応答を拒否する。送信済み要求は取り消せず、最大6秒の終了待ち中も追加要求・更新インストールを抑止する。終了時に許可を含め消去し、起動・許可だけでは照会しない。
