# 接続先名のオプトイン取得（2026-10-25）

## 操作と意味

通信の詳細、または設定の「接続先名」で、このセッションでのOSリゾルバー利用を許可する。既定はオフで、許可だけでは照会しない。現在の実測接続を選択して「このIPの名前を取得」を押した場合だけ、OSの名前取得処理を開始する。ブラウザ／デモからは実行しない。

IPがOS設定のDNS等へ送られる可能性を、許可のそばに表示する。LAN探索の名前取得とは独立した許可であり、オフにしても別途承認したLAN探索の処理は変更しない。結果はOSリゾルバー由来と表示し、hosts・OSキャッシュ・DNS・mDNSなど実際の応答経路は確定しない。DNSSECや名前の所有者も検証しない。

逆引き名は、そのアプリが使用した元のホスト名とは限らない。同じIPを複数のアプリ／サービスが使う場合もある。常に「名前は未検証」と表示し、署名・ルール・適用状態・TLS確認対象名・アプリ識別・安全性の判定に使用しない。Connection.destinationと保存ルールは変更せず、元のIPとポートを維持する。名前は通常検索の対象に自動追加しない。

## Rust側の境界

- `destination_names::Machine`を共有Sessionが保持する。起動時は無効で、許可・結果・待機状態は文書／バックアップ／ディスクへ保存しない。
- 有効化は期待operationと現在の実測モード・観測成功・新しいネットワーク情報を照合する。古い有効化要求が取消後に再有効化することを拒否する。
- 取得には現在のConnection ID、元のIP文字列、期待operationを要求する。履歴・終了済み接続・別のIP・デモ・更新インストール中・許可なしからの開始を拒否する。自由入力の名前やURLは受け付けない。
- IPv4／IPv6のリテラルunicastを対象にする。ループバック、未指定、マルチキャスト、IPv4の0/8・224以上、IPv6リンクローカルとスコープ付きアドレスを拒否する。IPv4-mapped IPv6も内部IPv4の条件を適用し、スコープを落として照会しない。
- 実行は固定の`/usr/bin/dscacheutil -q host -a ip_address <検証済みIP>`だけ。シェルや任意引数は使わない。最大1ワーカー、開始間隔10秒、コマンド最大6秒、stdout 8KiB。前後のifconfigによる確認時間は別であり、操作全体が6秒で終わるとは保証しない。
- networkの既知のupインターフェース／アドレス／マスク／familyをソートして照合する。時刻だけの更新では失効させない。前後の確認と既存観測で変化やエラーを検出したら失効する。同じアドレスを保つ経路／DNS設定／VPNの変化は検出できない。
- OS応答のブロックに、照会した正確なIPがあることを確認する。名前はASCII／Punycodeのhostnameラベル・全253バイト／1ラベル63バイトの範囲に限定し、URL・HTML・制御文字・bidi文字・IPの名前・不正なラベルを採用しない。複数候補からの完全な名前一覧は提供しない。
- 最大64件をメモリに保持し、超過時は古い結果から破棄。同じIPの再取得開始時は古い結果を除去する。取得元・アプリが記録した完了時刻・resolved／no_name／invalid_name／failed／timed_outを保存する。5分経過を単調時計で「古い結果」と表示し、DNS TTLや有効期限と解釈しない。
- 取消・消去はoperationを進め、子プロセスの取消フラグを立てる。オフ・デモ切替・観測失敗・検出したネットワーク変更では名前を消去し、許可も失効する。遅延結果は、再度許可していても古いoperationなら破棄する。すでにOSへ送った要求やOSキャッシュを取り消せるとは保証しない。
- 取消済みでも実ワーカーの終了まではbusy枠を保持し、連続取消／再開でワーカーが増えないようにする。その間は更新インストールを拒否する。更新適用中にも利用許可の取り消し／結果消去は可能。

## 表示

通信マップの接続先行と、ドッキング／フローティングの通信詳細に、名前・未検証・取得元・確認時刻を表示する。5分経過・取得失敗も区別する。名前はJSXのリテラル文字列で描画し、リンクやHTMLとして解釈しない。UIは入力と操作中の見せ方だけを持ち、許可・結果・実行状態はRustの共有Snapshotを表示する。3言語に対応する。

## Network Extensionからの名前

Appleの[remoteHostname仕様](https://developer.apple.com/documentation/networkextension/nefiltersocketflow/remotehostname)では、この値はURLSession／Networkなど名前指定APIから始まったフローの場合に限り設定される。常に取得できる値ではなく、今回のOSリゾルバー結果とは異なる取得元である。[remoteEndpoint](https://developer.apple.com/documentation/networkextension/nefiltersocketflow/remoteendpoint)も初回callbackで未設定の場合がある。

2026-10-25: ポリシーとは独立したv1観測契約を実装。既定オフ、明示操作で今後15秒のTCPフロー名を最大128件記録し、2秒以上あけた手動更新で取得する。追加のDNS照会はしない。Provider起動UUIDとrequest UUIDを照合し、署名主体・TCP・方向・送受信IP／port・初回観測時刻±3秒の対応を候補として照合する。最大64接続・各4名、15秒の鮮度制限。名前だけで接続を本人確認しない。

名前表示は取得元・時刻・未検証の候補を併記する。検索は収集許可とは別の明示設定で、通常マップとRust GPU投影へ接続。名前はルール・署名・TLS確認名の根拠にしない。オフ、観測失敗、デモ、検出したnetwork変更、Provider起動世代の変化で消去し、古い応答を拒否する。送信済み要求は処理後15秒までProviderに残り得る。Provider停止後のstoreは再有効化を拒否する。OSリゾルバーの名前とフロー由来の名前は別の取得元のまま扱う。
