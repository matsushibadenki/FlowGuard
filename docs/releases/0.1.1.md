# FlowGuard 0.1.1

## 日本語

- 保護状態を明確にし、署名に基づくルール識別、確認待ちの方針、システム保護プリセットと緊急復旧を改善。
- 通信マップの集約表示、言語設定、通知・メニューバー、LAN／TCP／サービス確認と手動Syslog受信を追加・改善。
- macOS標準ファイアウォール用ヘルパーと、最大10,000接続のネイティブGPU概要表示を追加。
- 署名済み更新経路の検証と、本体・拡張機能のバージョン管理を改善。

Apple Silicon向け。拡張機能・ヘルパーの有効化には利用者の操作とOS承認が必要です。観測やルール保存だけで遮断済みとは表示しません。実OS適用、Retina／複数ディスプレイ、稼働中拡張機能の更新など未検証項目はROADMAPのPendingを参照してください。

## English

- Clearer protection status, signing-based rule identity, configurable ask fallback, system protection presets and emergency recovery.
- Improved application-grouped map, language controls, notifications/menu bar, LAN/TCP/service checks and manual Syslog reception.
- Added a macOS firewall helper and a native GPU overview for up to 10,000 connections.
- Improved signed-update verification and host/extension bundle versioning.

Apple Silicon build. Extension/helper activation requires user action and OS approval. Observation or saved rule intent does not imply enforced blocking. See ROADMAP Pending items for real OS enforcement, Retina/multiple displays and updating an active extension.

## 简体中文

- 明确保护状态，改进签名规则身份、可配置的询问超时策略、系统保护预设及紧急恢复。
- 改进按应用聚合的地图、语言设置、通知／菜单栏、LAN／TCP／服务检查和手动Syslog接收。

适用于Apple Silicon。启用扩展或辅助程序需要用户操作及系统批准。观测或保存规则意图不代表阻止已生效。系统实际防护、Retina／多显示器及运行中扩展更新等未验证事项见ROADMAP的Pending项目。
